# 🍽️ RUFood

Sistema de gerenciamento e pedidos do Restaurante Universitário, desenvolvido em **Java** (com **Maven**) como trabalho final da disciplina de **Orientação a Objetos** da **UFJF**.

## 🚀 Funcionalidades
* Login e identificação de perfis de usuários.
* Consulta de cardápio e gerenciamento de pedidos *(ajuste conforme o seu sistema)*.
